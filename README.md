# 🌿 Ateliê Copta

Landing Page desenvolvida para o **Ateliê Copta**, um ateliê de peças artesanais voltadas para decoração, iluminação e presentes afetivos.

O projeto busca transmitir uma identidade visual sofisticada, acolhedora e minimalista, valorizando o conceito de que cada peça conta uma história.

---

## ✨ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 🎨 Design

O site foi desenvolvido utilizando uma paleta de cores inspirada na identidade visual do Ateliê Copta:

- Verde Musgo
- Terracota
- Rosa Suave
- Off White

Tipografia:

- **Berkshire Swash** (títulos)
- **Montserrat** (textos)
